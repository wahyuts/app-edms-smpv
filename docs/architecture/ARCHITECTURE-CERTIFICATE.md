# Source of Truth Policy

Mulai saat sertifikat ini diterbitkan:

- Seluruh dokumen di atas berstatus **FROZEN**.
- Tidak diperbolehkan melakukan perubahan langsung terhadap Source of Truth.

- Source of Truth menjadi referensi tunggal (Single Source of Truth) untuk seluruh aktivitas engineering.

# Change Management Policy

Apabila terdapat permintaan perubahan dari stakeholder atau client setelah sertifikasi ini diterbitkan, maka perubahan **TIDAK BOLEH** dilakukan secara langsung terhadap dokumentasi.

Seluruh perubahan wajib mengikuti alur berikut:

```
Client Request
        │
        ▼
Change Request (CR)
        │
        ▼
Impact Analysis
        │
        ▼
Product Owner Approval
        │
        ▼
Source of Truth Update
        │
        ▼
Re-Certification (Jika Diperlukan)
        │
        ▼
Implementation
```

# Governance Statement

Seluruh implementasi wajib mematuhi:

- Business Workflow
- Product Requirement Document (PRD)
- API Contract
- Database Schema
- Security Policy
- Decision Log

Apabila terjadi perbedaan interpretasi antar dokumen, maka urutan authority yang berlaku adalah:

```
Business Workflow
        ↓
PRD
        ↓
UI Documentation
        ↓
Frontend Architecture
        ↓
Data Layer
        ↓
Backend Blueprint
        ↓
Implementation
```

Authority dengan level lebih rendah **tidak boleh** mengubah keputusan yang berasal dari authority di atasnya.
